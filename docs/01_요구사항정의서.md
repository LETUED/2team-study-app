## 01. 개요

**목적**

스터디를 모집하고, 신청을 받아 참여자를 확정한 뒤, 모집자와 참여자가 연락할 수 있는 정보를 공유하는 스터디 모집 게시판.

**범위**

```
회원가입 ▶ 모집글 등록 ▶ 참여 신청 ▶ 수락 · 거절 ▶ 마감 ▶ 모임 페이지(연락처 공유)
```

게시판은 모집글 용도로만 사용한다. 후기 기능은 두지 않는다.

## 02. 사용자 정의

| 구분 | 설명 | 할 수 있는 것 |
| --- | --- | --- |
| 손님 | 가입하지 않은 사람 | 목록 화면에서 모집글을 보거나 검색할 수 있음 |
| 회원 | 가입한 사람 | 모집글을 올릴 수 있음 · 다른 모집글에 참여를 신청할 수 있음 · (마이페이지) 자신이 올린 모집글을 확인할 수 있음 · (마이페이지) 자신의 신청 내역을 확인할 수 있음 |
| 모집자 | 스터디 글을 올린 사람 | 자신의 모집글의 신청 목록을 볼 수 있음 · 모집글을 마감할 수 있음 · 신청을 수락하거나 거절할 수 있음(되돌릴 수 없음, 정원·기한 있음) |
| 신청자 | 모집글에 신청해 모집자에게 수락된 사람 | 모임 페이지에서 참여자 신상정보(컨택용)를 볼 수 있음 |

## 03. 핵심 시나리오

**시나리오 1 · 모집자**
```
1. 로그인한 회원이 스터디 모집글 작성
2. 신청 목록에서 신청자 확인
3. 수락 또는 거절
4. 정원, 기한 지나면 마감
```

**시나리오 2 · 신청자**
```
1. 목록, 검색으로 모집글 탐색
2. 로그인이나 회원가입으로 모집글 참여 신청
3. 비회원이 신청 버튼을 누르면 "로그인이 필요한 기능입니다" 팝업 후 회원가입 페이지로 이동
```

**시나리오 3 · 스터디 마감**
```
1. 모집자가 직접 모집글을 마감하거나 정해진 기한에 도달함
2. 마감된 모집글은 추가 신청 접수 불가
3. 마감 후, 신청자·모집자 간 연락 가능한 정보를 모임 페이지에서 공유
```

## 04. 기능 요구사항

**모집글**

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| FR-01 | 모집글 목록 조회 | 비회원도 가능. 페이지 번호로 조회(인덱스는 검색 결과 내 순번, DB 식별자 아님). 목록에 마감상태·제목·정원 표시 `[마감상태] 제목 {정원}` |
| FR-02 | 모집글 키워드 검색 | 비회원도 가능 |
| FR-03 | 모집글 작성 | 제목·내용·정원·기한 설정. 정원 최소 2(모집자+신청자1)~최대 100. 기한은 작성일 이후만 |
| FR-04 | 모집글 상세 조회 | 마감상태·제목·내용·정원·기한 표시 |
| FR-05 | 모집글 수정 | 작성자만 |
| FR-06 | 모집글 삭제 | 작성자만 |
| FR-07 | 모집글 마감 | 작성자 수동 마감 + 정원참/기한도달 자동 마감. 마감되면 신청 버튼 비활성화 |

**신청**

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| FR-08 | 참여 신청 | 모집자 외 회원만, 마감 전만. 자기소개 작성 후 승인대기 |
| FR-09 | 비회원 신청 시도 처리 | "로그인이 필요한 기능입니다" 팝업 → 회원가입 페이지 이동 |
| FR-10 | 신청 목록 조회 | 모집자용 |
| FR-11 | 신청 수락/거절 | 되돌리기 불가 |

**모임 페이지**

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| FR-12 | 모임 페이지 등록 | 수락된 신청자를 참여자로 등록 |
| FR-13 | 모임 페이지 조회 | 모집자 + 수락된 신청자만 접근 |
| FR-14 | 참여자 신상정보 조회 | 모임 페이지 내 테이블, 컨택용 |

**후기**

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| FR-19 | 리뷰 등록 | 스터디가 마감되면 참여자는 후기를 남길 수 있다 |
| FR-20 | 리뷰 삭제 | 자신이 등록한 리뷰를 삭제한다 |
| FR-21 | 리뷰 조회 | 모집글 상세에서 후기 목록을 볼 수 있다 |

**마이페이지**

| 번호 | 기능 | 설명 |
| --- | --- | --- |
| FR-15 | 신상정보 등록/수정 | 최종 수정 전 비밀번호 재확인 |
| FR-16 | 내 모집글 현황 목록 | `[마감상태] 제목 (신청자수/정원)` |
| FR-17 | 내 신청 현황 목록 | `[신청현황] 제목` |
| FR-18 | 내가 참여 확정된 모임 목록 | 모임 페이지 바로가기용 |

세는 법 확인: 신청(FR-08) → 신청 목록(FR-10) → 수락/거절(FR-11) → 모임 등록(FR-12) 체인이 끊기지 않음.

## 05. 업무 규칙

**모집글**

| 번호 | 규칙 | 어긴 경우 |
| --- | --- | --- |
| BR-01 | 정원은 최소 2명, 최대 100명이어야 한다 | 400 |
| BR-02 | 기한은 작성일 이후만 설정 가능하다 | 400 |
| BR-03 | 모집글 수정·삭제·수동마감은 작성자만 가능하다 | 403 |
| BR-04 | 정원이 차거나 기한이 지나면 자동 마감된다 | 상태전이 |
| BR-05 | 마감된 모집글은 신청을 받을 수 없다 | 400 |

**신청**

| 번호 | 규칙 | 어긴 경우 |
| --- | --- | --- |
| BR-06 | 신청은 회원만 가능하다 | 403 |
| BR-07 | 모집자 본인은 자신의 모집글에 신청할 수 없다 | 400 |
| BR-08 | 신청은 취소할 수 없다(낙장불입) | - |
| BR-09 | 신청 수락·거절은 모집자만 가능하다 | 403 |
| BR-10 | 한 번 수락·거절한 신청은 되돌릴 수 없다 | 400 |

**모임 페이지**

| 번호 | 규칙 | 어긴 경우 |
| --- | --- | --- |
| BR-11 | 모집자와 수락된 신청자만 접근 가능하다 | 403 |

**후기**

| 번호 | 규칙 | 어긴 경우 |
| --- | --- | --- |
| BR-13 | 리뷰는 마감된 스터디의 참여자만 등록할 수 있다 | 403 |
| BR-14 | 리뷰 삭제는 작성자 본인만 가능하다 | 403 |

**마이페이지**

| 번호 | 규칙 | 어긴 경우 |
| --- | --- | --- |
| BR-12 | 신상정보 최종 수정 전 비밀번호 재확인이 필요하다 | 401 |
